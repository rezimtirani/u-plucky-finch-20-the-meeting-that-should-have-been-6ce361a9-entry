One single-line joke about a meeting that should have been an email: an hour spent deciding the meeting should have been an email, then a follow-up booked to discuss the email.

> We spent an hour in a meeting deciding the meeting should have been an email, then booked a follow-up to discuss the email.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
